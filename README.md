# Game

Silt County, the early co-op mud-truck slice, lives in [`SiltCounty/`](SiltCounty/README.md).

That folder is its own Unreal Engine 5 project (`SiltCounty/SiltCounty.uproject`). Keep other games in this repo, including anything under a ValleyGod folder, separate from it.

Open, play, and 2-player test steps are in [SiltCounty/README.md](SiltCounty/README.md). Mud, standing water, and wet-ground materials are described in that same readme under "Mud, water, and wet ground."
